# التعويضات المتحركة — ملف المتابعة

البلاغ (المالك، 12 تشرين الثاني 2026): «كأنو ما عنا تعويضات متحركة». الجهاز الكامل أو الجزئي كان
يُسجَّل «علاجاً جماعياً على الفك»: جلسة بلا رسم ولا أسنان معوَّضة، والجهاز الموجود مسبقاً لا يُسجَّل.

المراجعة قبل القرار: Open Dental (Paint Type «Denture» · Arch/Tooth Range) · Sensei Cloud
(المنطقة ← كامل/جزئي ← تأكيد الأسنان المفقودة) · Denticon (تحديد الأسنان ثم Denture).

## النموذج

| الطبقة | التمثيل |
|---|---|
| الكتالوج | `treatments.target_part` = `denture_full` أو `denture_partial` · الفئة `prosth_removable` («تعويضات متحركة») |
| المخطط | صفّ `teeth_status` بسطح محجوز `DENTURE` لكل سن يعوّضه الجهاز · صفوف الجهاز الواحد تتشارك `unit_id` |
| السجل | جلسة فكّ واحدة لكل جهاز (`tooth_num` فارغ · `arch` U/L · الوصف يسمّي الأسنان) · `unit_id` = معرّف الجلسة |
| بلا مال | «موجود مسبقاً» و«محوّل» = صفوف مخطط وحدها بمعرّف وحدة عشوائي |
| الذاكرة | `dentureMap` بـ`pp-denture.js` منفصلة عن `teethMap` · الرسم طبقة تُضاف بعد `renderTeeth` |
| المال | صفر مسار جديد — جلسة فكّ عادية ثم `reallocatePatientFunds` |

ثوابت يحرسها `scripts/prove-denture.js`:

- مخطط بلا جهاز لا يتغيّر فيه بايت (الطبقة حاضرة = الطبقة غائبة).
- كل محو أو تحديث للسن بلا سطح يحمل `.neq('surface', 'DENTURE')` (13 موضعاً).
- صفوف الجهاز تُدرَج (insert) لا تُدمَج — صفّ قائم على السن يُسقط العملية.
- فشل رسم الصفوف يسحب الجلسة؛ لا نصف حفظ.

## ج2-أ — التعايش مع الزرعة والجسر

صفّ الجهاز بسطحه المحجوز لا يزاحم صفّ الزرعة (`WHOLE`) ولا دمية الجسر (`PONTIC`)، فيجتمعان على السن.

| الحالة على السن | الجهاز الجزئي | الجهاز الكامل |
|---|---|---|
| مقلوع (منجز) | يُحدَّد مسبقاً | ضمن الجهاز |
| زرعة مخطّطة أو دمية جسر مخطّط | يُضاف بنقرة صريحة — الجهاز بديل | ضمن الجهاز تلقائياً — بديل والخطة تبقى |
| زرعة منجزة | لا يعوّضها | جهاز فوق الزرعات — الزرعة تبقى تحته |
| جسر منجز (دعامة أو دمية) | مانع | مانع — يُسجَّل جزئياً |
| قلع مخطّط | مانع (ج2-ج) | مانع (ج2-ج) |
| سن قائم | مانع — يُقلع أولاً | يُسأل عن تعليمه «مفقوداً مسبقاً» |

والعكس: السن الذي يعوّضه جهاز يقبل زرعة أو جسراً (من نافذة السن، التحديد المتعدد، الفحص الأولي).
حافظ المسافة وحده يبقى مرفوضاً.

الرسم: السن الصناعي يُرسم على شبح السن المقلوع. فوق دمية جسر (بديل بالخطة) تُرسم قاعدة الجهاز فقط
فتبقى الدمية ظاهرة.

الزرعة تحت الجهاز (v719 — بلاغ المالك 14/11/2026: «الجهاز راكب على الزرعات، ما بيكون للزرعة تاج»):
تاج الزرعة يُخفى وبرغيها يبقى، وسن الجهاز يُرسم فوقه بالمنظرين؛ عنوان الخلية يسمّي الجهاز. الإخفاء على
الرسم وحده — إزالة الجهاز تعيد الزرعة بتاجها.

السن لا يعود قائماً تحت جهاز: إزالة الزرعة من زرّها، حذف جلستها، أو إلغاء ختمها بالفحص الأولي —
كلها تعيد السن «مفقوداً». «سليم» لا يزيل زرعة تحت جهاز. إزالة جسر يمرّ فوق سن الجهاز تمرّ
(المقلوع يبقى مقلوعاً).

## قرارات المالك

- لا إضافة رجعية للعلاجات الأربعة للحسابات القائمة — تُضاف بزرّ «الافتراضي».
- الفئتان منفصلتان: «تعويضات ثابتة» (تاج، جسر) و«تعويضات متحركة» (كامل، جزئي).
- النقاط الرمادية «موجود مسبقاً» تُخفى عن السن الذي يعوّضه جهاز.

## حدود معروفة

- جهاز واحد على السن (المفتاح الأساسي للصف) — يُرفع بـج2-ب.
- خطة العلاج لا تسِم الجهاز والزرعة/الجسر «أ/ب» بعد: جلسة الجهاز جلسة فكّ بلا قائمة أسنان (ج2-ب).
- لا يُلغى قلع سن والجهاز عليه — يُزال الجهاز أولاً.
- بوابة المريض تعرض الاسم المبسّط للجهاز بلا الفك.
- فحوص `delSession` بالمثبت ثابتة (الدالة بملف الصفحة خارج عُدّة jsdom).
