# مراجعة أدلة الأقسام (guides.js) — 20 تشرين الثاني 2026

طلب المالك: «راجع دليل الاستخدام بشكل مفصّل وتأكّد أن كل شيء صحيح: المنطق والشروح والتسلسل».
الأدلة (17 دليلاً: «📖 دليل هذا القسم» بكل صفحة + «مركز التعلّم») كُتبت في 13 تشرين الأول وتغيّرت الصفحات بعدها.
روجعت **كل جملة** مقابل الصفحة نفسها (الكود، لا الذاكرة). ما وُجد وصُحّح:

| الدليل | ما كان مكتوباً | الواقع بالصفحة |
|---|---|---|
| البداية · الإعدادات | «هوية العيادة: الاسم والهاتف والعنوان والشعار» | القسم فيه **اسم العيادة فقط**؛ رقم الواتساب في «قوالب WhatsApp»، ولا عنوان ولا شعار |
| البداية | «إعدادات المواعيد (مدة الموعد الافتراضية)» · «أوقات العمل» | «إعدادات المواعيد» = رسم عدم الحضور؛ المدة بـ«قوالب المواعيد»؛ أيام الدوام وساعاته بـ«الحجز الإلكتروني» |
| البداية · الموظفون | «لكلٍّ منهم رقمه السري» | الرقم السري لمن فُعّل له «يحتاج وصولاً للبرنامج» فقط |
| الإعدادات | «اختر القسم من القائمة الجانبية» · «تذكيرات WhatsApp للمواعيد» | تبويبات أعلى الصفحة (الحساب · العيادة · المساعد الذكي · متقدّم)؛ اسم القسم «قوالب WhatsApp»؛ ونقص «استمارة المريض» و«بوابة المريض» |
| لوحة التحكم | «نبض اليوم: اضغط أي موعد لفتحه» | النقر يفتح **ملف المريض** |

| المواعيد | «اختر المريض (أو أنشئه)» | النافذة لا تُنشئ مريضاً؛ الاسم غير المطابق يُحفظ بلا ربط بملف |
| ملف المريض | «اختر العلاج من الأدوات ثم اضغط السن» | العكس: **السن أولاً** ثم العلاج وحالته بالنافذة |
| ملف المريض | «المساعد الذكي» ضمن «أدوات» · «صور الأشعة» بالملفات | المساعد زرٌّ مستقل؛ رفع الأشعة مقفل «قريباً»؛ ونقص تبويب «فحص اللثة» |
| قائمة العلاجات | «استعادة الافتراضي تعيد القائمة الأصلية — بحذر» | تضيف الناقص فقط ولا تحذف ولا تعدّل شيئاً |
| قائمة العلاجات | «يحتاج مخبراً» · الخصم «تلقائياً» | الاسم «يحتاج إرسالاً للمخبر»؛ «🧰 المواد» خلف «⋯ المزيد»؛ الخصم **بعد تأكيد** |
| أطباء العيادة · الموظفون | «لون الطبيب يظهر في جدول المواعيد» · «حدّد أسعاراً خاصة» | اللون بجانب الاسم (الجدول يلوَّن بالغرفة)؛ السعر الخاص من نافذة العلاج بقائمة العلاجات |
| المخابر | يبدأ بـ«＋ طلب جديد» | لا طلب بلا مخبر مسجَّل ⇒ «＋ مخبر جديد» أولاً؛ وأُضيفت قاعدة «متأخر» |
| التصوير الشعاعي | يشرح القسم كأنه يعمل | القسم مقفل «قريباً» منذ تشرين الأول |
| المحاسبة | «اليوم، الشهر، أو فترة مخصّصة» | الأزرار: الشهر الحالي · السابق · آخر 3 شهور · السنة؛ ونقص «كشف اليوم» و«تقادم ذمم المرضى» |
| المصاريف · الرواتب | حقول ناقصة | أُضيفت «طريقة الدفع» و«الفترة التي تغطّيها الدفعة» (إلزامية) واقتراحُ المبلغ |
| التقارير | الترتيب يبدأ بـ«ملخّص الفترة» | رُتّبت كتبويبات الصفحة |

| سجل النشاطات | «افتح أي عملية لترى القيمة قبل التعديل وبعده» | **لا يوجد**؛ السطر وصفٌ فقط. وقواعد التنبيه كُتبت كما هي بالقاعدة |
| الموظفون | «إيقاف الحساب يمنعه من الدخول» | «تعطيل الحساب» يجعل الجهاز للقراءة فقط |

ومعها: ترتيب الأدلة صار ترتيب القائمة الجانبية (المرضى ← ملف المريض ← المواعيد…)، وأُضيفت «🧭 جولة تعريفية»
و«🧭 جولة مفصّلة» و«🧪 مريض تجريبي»، وزرّا نافذة الدليل («فهمت» · «كل الأدلة في مركز التعلّم») كانا يبقيان عربيَّين بالإنجليزية.

**الحارس** `scripts/check-guides.js` صار يفحص النص نفسه: كل تسميةٍ بين `<b>` موجودةٌ بصفحات التطبيق، وكل دليلٍ إنجليزيٌّ
كاملاً عبر المحرّك الحقيقي (5 طفرات ⇒ حمراء). لا يثبت صدق الجملة — ذلك لهذه المراجعة.
