## #1 — قياس الأداء «قبل» (30 أيلول 2026، بلا تعديل كود)
**المنهج:** Chromium حقيقي على الملفات الحيّة (HEAD `c67786b`) بعميل Supabase مصطنع يؤخّر **كل طلب 400ms** (تقديرُ رحلة سوريا ↔ أوروبا)، بيانات فارغة (فالأرقام حدٌّ أدنى — البيانات الحقيقية تضيف طلبات).
**سجلات Supabase الحيّة (edge_logs):** طلباتُ سوريا تمرّ بـCloudflare مرسيليا (MRS) ولندن؛ **زمنُ السيرفر+القاعدة متوسط 47ms · p90 97ms** ⇒ القاعدة سريعة، **البطءُ من عدد الرحلات المتسلسلة عبر الشبكة**.

| الصفحة | طلبات Supabase | جولات متسلسلة | آخر ردّ (400ms/طلب) |
|---|---|---|---|
| لوحة التحكم | 50 | 11 | 4.7 ث |
| المواعيد | 33 | 13 | 5.7 ث |
| المرضى | 29 | 8 | 3.2 ث |
| بطاقة المريض | 46 | 11 | 8.8 ث |
| التقارير | 36 | 16 | 7.0 ث |
| المحاسبة | 54 | 8 | 3.3 ث |
| المخابر | 30 | 9 | 4.0 ث |
| المخزون / المصاريف | 22–23 | 8 | 3.1 ث |
(قائمة العلاجات 30 جولة = حلقة بذرٍ بسبب البيانات الفارغة المصطنعة — ليست حالة عيادة حقيقية.)

**الأسباب — بعد تتبّع مُطلِق كل طلب (مكدّس الاستدعاء عند `sb.from/rpc`) — تصحيحٌ للقراءة الأولى:**
سلسلةُ الإقلاع المشتركة (الشريط الجانبي · القفل · بوابة الاشتراك) **تعمل بالتوازي** مع بيانات الصفحة لا قبلها — تؤخّر الشريطَ الجانبي وعدّاداته (~6 جولات) لا المحتوى. **المسارُ الحرج هو سلسلةُ كل صفحةٍ نفسها: قراءاتٌ مستقلة تُنتظر واحدةً واحدة:**
1. **المواعيد (`init`):** أطباء ← كراسي ← أنواع ← إعدادات الواتساب ← هواتف المرضى ← الأعلام ← سجل التذكير ← **المواعيد نفسها تبدأ عند 3.7 ث** ← الجلسات ← المخابر ← الحجب ← طلبات الحجز = 12 جولة متتالية.
2. **التقارير:** جلسات ← دفعات ← مخابر ← دفعات أطباء، ثم الشيء نفسه للفترة السابقة مرتين = 12 جولة.
3. **لوحة التحكم (`loadDashboard`):** مرضى ← مواعيد ← إعدادات ← أعلام ← أمس/الهدف ← … ← المخابر ← غرفة الانتظار = ~10 جولات.
4. **بطاقة المريض:** قراءاتُها متوازية أصلاً (v_perf) — المحتوى عند ~1.6 ث؛ يتبقّى تكرارُ كتالوج العلاجات (`populateSessionTypes`) بعد الرسم.
5. **الشريط الجانبي (`refreshSidebarDynamic`):** طلب التجربة ← الإعدادات ← الخطة ← الخطط ← عدّاد المواعيد ← طلبات الحجز = 6 جولات (يفسّر #11 «العدّاد يتغيّر» و#16 «الشريط يظهر متأخراً»). + تكرار: الإعدادات حتى 7 مرات · طلب التجربة 3 · الأدمن 3.
