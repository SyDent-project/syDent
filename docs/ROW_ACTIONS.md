# جولة أزرار الصفوف الجانبية (v469 →)

**طلب المالك (21 أيلول 2026):** توحيد الأزرار الجانبية بصفوف القوائم والجداول بكل المنصة على معيارٍ واحد. المرجع: أزرار «طلبات الحجز» بصفحة المواعيد.

## المعيار
- الطقم: `SYDENT ROW-ACTIONS KIT` بـ`theme.css` — `.sy-acts` (`.sy-acts-grid` للوحة أزرارٍ بشبكة داخل بطاقة) · `.sy-act` · `.sy-act-danger` · `.sy-act-ico` · `.sy-act-more` (⋮ قائمة «المزيد»).
- كلُّ فعلٍ **أيقونة + كلمة**. الأيقونة وحدها لرابط الواتساب السريع (📱) وقائمة «المزيد» (⋮) فقط، بـ`title` و`aria-label`.
- الترتيب: الفعلُ الأساسي ← تعديل ← بقيةُ الأفعال ← الأحمر (حذف/رفض/إلغاء) ← الأيقونات.
- ثلاثةُ ألوانٍ بمعنى ثابت (v472، طلب المالك «لازم تميّز»؛ اتّسع البرتقالي بـv474): `-primary` أخضر يتقدّم (واحدٌ بالصف) · `-warn` برتقالي لإعادة العمل أو الإيقاف القابل للتراجع (تعطيل) · `-danger` نصٌّ أحمر للحذف/الرفض/الإلغاء. الباقي محايد. اللونُ مربوطٌ بالمعالج بقائمة `PRIMARY_RE`/`WARN_RE` بالحارس.
- بالموبايل (≤820px) الأزرار سطرٌ ثانٍ كامل العرض وارتفاعها 40px.
- لا `style` مضمَّن على الزر، ولا قاعدة محلية تعيد تعريفه (الاستثناءات بالاسم في `KIT_EXCEPTIONS`).
- الصلاحيات (`data-sub-write` · `data-role-block` · `data-doctor-inactive-block`) و`data-test` تبقى على الزر كما هي.

## التحقّق من عمل الأزرار (لا الشكل وحده)
- `scripts/dom-smoke/real-render/run.py` (بالبوابة): **دوالُّ العرض والحفظ الحقيقية** بكل الحالات بمتصفحٍ حقيقي — الخاناتُ والامتدادُ والألوانُ والترتيبُ والاصطفافُ الفعلي، والمجموعاتُ بالأدمن، وحفظُ وقت المصروف والراتب. أيُّ عارضٍ جديد لأزرار صفوف يُضاف إليه.
- `python3 scripts/prove-row-actions-wiring.py` — كلُّ زرٍّ بمعالج بالملفات المُرحَّلة يحمل **نفسَ** الدوالّ والفعلَ المفوَّض وdata-test ووسومَ الصلاحيات كما قبل الجولة (يُضاف الملفُّ الجديد إلى `FILES` عند ترحيله).
- `dom-smoke/row-actions`: كلُّ زرٍّ ظاهر **قابلٌ للنقر فعلاً** (يُمرَّر للشاشة ثم `elementFromPoint` بمركزه — لا عنصرَ يغطّيه) ويستجيب للمؤشّر.
- E2E على المستأجر الحيّ بكل دفع (بوابةُ النشر): حذفُ موعدٍ من القائمة بزرّ الطقم · قائمةُ ⋮ وحذفُ مريض · تبويبا الجلسات والمدفوعات.

## ترحيلُ صفحة
1. أضف ملفاتها إلى `MIGRATED` بـ`scripts/check-row-actions.js` مع فئاتها القديمة.
2. أضف صفوفها الحقيقية (بحاوياتها ومراسيها) إلى `PAGES` بـ`scripts/dom-smoke/row-actions/build-harness.js`.
3. احذف CSS الأزرار القديم بعد قراءة قيمه (#636).
4. `bash scripts/validate.sh` + لقطاتٌ بالثيمين والمقاسين ← مراجعة المالك («تمام») قبل الصفحة التالية.

## الاصطفاف عبر الصفوف (v482)
- جدولٌ أزرارُ صفوفه متغيّرة ⇒ `.sy-slots` + `style="--sy-slots:__SY_SLOTS__"` على الحاوية + `data-slot` لكل زر + `data-span-if="N"` لزرٍّ يمتدّ فوق خانة N إن غابت بصفّه، ثم `SySlots.finalize(html, {1:'…px', …})` على HTML الجدول كله (v484: تُطوى الخاناتُ غير المستعملة بأي صفّ). خانةُ الأزرار بالجدول ملتصقةٌ بنهاية الصفّ (الطقم). العروضُ تُقاس بالمتصفح بالخط الحقيقي + هامش، والمثبتُ يرفض أي تسميةٍ مقصوصة أو عمودٍ مائل.
- جدولٌ جديد أزرارُه متغيّرة يدخل الخانات قبل أن يُعدّ مُرحَّلاً.
