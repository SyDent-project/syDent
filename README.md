# SyDent

نظام SaaS متعدّد المستأجرين لإدارة عيادات الأسنان — عربي RTL، مباشر على **https://sydent.app**.

**HTML/CSS/JS صِرف** (بلا build) + Supabase + Cloudflare Pages (نشر تلقائي من `main`).

| ابدأ من هنا | |
|---|---|
| `DEVELOPER_HANDOFF_AR.md` | وثيقة تسليم المشروع الكاملة (بنية، أسرار، خارطة الإطلاق) — **المرجع الموثوق الوحيد**؛ ابدأ من الملحق ج |
| `docs/OPERATIONS_AR.md` | دليل التشغيل الموحّد: سير العمل، النسخ الاحتياطي، الاستجابة للحوادث |
| `scripts/README.md` | أدوات الجودة: `validate.sh` (قبل كل commit) · `cache-bust.sh` · `check-mirrors.js` |

⚠️ `book.html` (بوابة الحجز العامة) **لا يُمسّ** في التعديلات الجماعية.
